# SwimLaneDiagrammer

This project is a Swimlane Diagramming Application built with React, TypeScript, and Vite.

## Features

- **Swimlane Diagramming**: Create pools and lanes to organize your process flow.
- **Shape Management**: Add, move, resize, and connect various shapes.
- **Drag Selection**: Select multiple shapes by dragging a selection box.
- **Undo/Redo**: Full history support for all actions.
- **Alignment Tools**: Align multiple selected shapes easily.
- **Project Management**: Save and load projects locally using IndexedDB.
- **Export**: Export diagrams to PDF and Excel.

## Tech Stack

- React
- TypeScript
- Vite
- Zustand (State Management)
- React Flow (Drag & Drop logic inspiration)
- Dexie.js (IndexedDB wrapper)

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Build for production: `npm run build`
